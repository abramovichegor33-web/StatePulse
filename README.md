Искал для себя удобный инструмент, чтобы в течение дня быстро чекать самочувствие — уровень физической энергии, ясность ума и моральный ресурс. Большинство существующих приложений либо перегружены сложными анкетами и платными подписками, либо написаны на тяжелых веб-оболочках (Electron) и впустую тратят батарею ноутбука, либо отправляют личные заметки на сторонние серверы.

В итоге решил сделать свой вариант — максимально легкий, минималистичный, живущий прямо в строке меню (Menu Bar) и эстетически вдохновленный Things 3 и Linear. Делал под свои задачи, но выкладываю в открытый доступ: возможно, кому-то тоже окажется полезным.

### Что внутри

- **Чек-ин за 5 секунд из строки меню**:
  - Быстрый вызов по клику на иконку или горячей клавише `Option + Space`.
  - Тактильные шкалы оценки (1–10) с плавной регулировкой.
  - Разбивка по 4 фазам суток (`Утро`, `День`, `Вечер`, `Ночь`) с аккуратными индикаторами заполнения.
  - Быстрые контекстные теги в один клик (`Недосып`, `Тренировка`, `Стресс`, `Отдых` и др.) с возможностью добавлять свои прямо на лету (и удалять/восстанавливать правым кликом).
  - Поле для короткой мысли или заметки.
- **Гибкая настройка шкал**:
  - Любую шкалу можно переименовать, изменить ее цвет и иконку или добавить собственные показатели (например, *«Уровень стресса»*, *«Креативность»*).
- **Аналитика и инсайты**:
  - **Тепловая карта года** в стиле коммитов GitHub (52 недели) с интерактивным просмотром всех срезов каждого дня.
  - **Ритм дня (24 часа)**: почасовой профиль энергии от пробуждения до сна и средние значения по фазам суток.
  - **Интерактивные графики трендов** (Swift Charts) со скользящей средней за 7 дней.
  - **Поиск скрытых закономерностей**: алгоритм автоматически находит связи (например, насколько недосып роняет фокус или как тренировки повышают тонус).
- **История и поиск**:
  - Удобная хронология всех записей с фильтром по тегам и мгновенным поиском по тексту заметок. Любую запись можно отредактировать или удалить.
- **100% приватность и локальность**:
  - Все данные сохраняются исключительно локально на вашем Mac в базе SQLite (WAL-режим). Никаких облаков, аккаунтов и трекинга.
  - Поддержка экспорта и импорта всей базы в JSON и CSV (RFC 4180).
- **Энергоэффективность**:
  - Написано на чистом **Swift + SwiftUI**.
  - Окно аналитики выгружается из памяти при закрытии. В режиме ожидания приложение потребляет ~40 МБ RAM и **0.0% CPU**.

### Сборка и запуск

Проект собирается стандартными средствами Xcode / Swift Package Manager без необходимости устанавливать сторонние зависимости:

```bash
# Клонировать репозиторий
git clone https://github.com/abramovichegor33-web/StatePulse.git
cd StatePulse

# Собрать готовое приложение (.app)
chmod +x Scripts/build_app.sh
./Scripts/build_app.sh

# Запустить собранное приложение
open build/StatePulse.app
```

При желании `StatePulse.app` можно просто перетащить в системную папку **«Программы»** (`/Applications`), чтобы приложение всегда было под рукой.
